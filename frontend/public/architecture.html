1. Master Data & Governance A1 - A7
customers & tiers Table
  • PK id serial
  • name, email varchar
  • FK tier_id Bronze|Silver|Gold
  • credit_limit numeric
  • payment_terms Immediate|30d|60d
products & categories Catalog
  • PK id serial
  • FK category_id integer
  • base_price, cost numeric
  • is_recurring boolean
  • sku, unit varchar
discount_rules Margin Rules
  • PK id serial
  • FK category_id integer
  • min_margin_pct e.g. 20%
  • max_discount_pct e.g. 15%
  • approval_level manager|finance
Governance Matrix Defines tier-based discount ceilings, required margins per product category, and credit term restrictions.
2. Dynamic Quoting Engine B1 - B3
quotes Core Order
  • PK id serial
  • quote_number QT-2026-XXXX
  • FK customer_id customers
  • FK rep_id users
  • status draft|pending|approved
  • blended_risk_score 0 - 100
  • grand_total numeric
  • portal_token unique token
quote_lines Line Items
  • PK id serial
  • FK quote_id quotes
  • FK product_id products
  • quantity integer
  • unit_price numeric
  • discount_pct numeric
  • margin_pct calculated
  • is_recurring boolean
Risk Score Algorithm Evaluates blended margin, customer payment history, and credit limit headroom:
Risk = (100 - Margin%) * 0.5 + CreditExposure * 0.5
3. Approvals & Risk Routing B4 - B5
approval_logs Audit Trail
  • PK id serial
  • FK quote_id quotes
  • FK reviewer_id users
  • level manager | finance
  • action approved|rejected
  • reason text
  • created_at timestamp
Smart Escalation Logic • Auto-Approved: Discount ≤ Tier Cap & Margin ≥ Category Min.
• Level 1 (Sales Mgr): Discount > Cap by ≤ 10%.
• Level 2 (Finance/Ops): Negative margin, discount > 10% over cap, or credit limit exceeded.
upsell_rules Recommendation
  • PK id serial
  • FK source_product products
  • FK suggested_product products
  • rank, min_margin_pct rules
4. Portal & Negotiation C1 - C3
portal_comments Live Feed
  • PK id serial
  • FK quote_id quotes
  • author_type customer | rep
  • message text
  • counter_discount numeric
  • created_at timestamp
Token Magic Link Experience Customer accesses quote without passwords at:
/portal/:token
• Real-time price breakdown
• Counter-offer submission triggers re-approval
• One-click acceptance transitions quote to fulfillment!
Live Status Sync When an invoice is paid or delivery moves, the portal updates seamlessly to display official order and payment receipts.
5. Fulfillment & Billing D1 - E3
warehouses & stock Inventory
  • PK id serial
  • shipping_cost_weight 1.0x - 2.5x
  • quantity_on_hand physical
  • quantity_reserved allocated
  • reorder_level, batch rules
subscriptions MRR / ARR
  • PK id serial
  • FK quote_id, customer links
  • interval monthly|quarterly
  • quantity, unit_price pricing
  • status active|paused|cancelled
billing & invoices Revenue
  • PK id serial
  • invoice_number INV-2026-XXXX
  • FK quote_id, customer links
  • total, status draft|posted|paid
